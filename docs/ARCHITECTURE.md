# 模块地图与文件契约

## 数据流

`collector → selection → ai → pipeline → store → site / mailer`。

`models` 是公开字段与内部数据边界；`SourceItem` 的 excerpt 只在内存使用，写入公开日报时转换为不含 excerpt 的 `SourceRef`。`DraftBundle` 不进入 Store。

| 模块 | 职责和约束 |
|---|---|
| `config/models` | 严格校验配置和数据，拒绝未知字段、危险链接和越界数量 |
| `network` | DNS 结果必须全部为公网地址；固定连接到已验证 IP，用原主机名做 Host/SNI；逐次检查重定向 |
| `collector` | RSS/Release/官方 HTML 采集、时间校验、纯文本清洗、条件请求、单源异常隔离 |
| `selection` | 稳定 URL、标题/实体/版本/事件类型、SimHash 转载识别、独立来源门槛与历史去重 |
| `ai` | 免费条件与 Lite/Flash 双模型白名单、固定 Developer API、结构化输出、输入证据 ID/数字检查、调用前持久化配额 |
| `pipeline` | 确定期号与窗口、正常/降级日报、冻结修订、覆盖和历史索引维护 |
| `store` | 原子 JSON 写入、模型二次校验、只暂存 state.json/digests、仅 news-data 分支可远程推送 |
| `site` | 自动转义、项目基础路径、当前/历史/修订网页、产物路径白名单 |
| `drafts` | 同一日报的两种确定性排版，官方字数库 stdin 桥接，草稿不出现在进程参数 |
| `mailer` | 私人 MIME、文本附件、TLS SMTP、发送前标记、明确失败与结果未知分类 |
| `cli/scripts` | 安全日志、手动入口、默认分支调度桥接、部署确认和通知协调 |

## 公开状态

`state.json` 包含覆盖时间、滚动 AI 请求时间/令牌预留、ETag/Last-Modified、来源错误码、期号修订的技术状态及 90 天事件索引。没有收件人、主题、正文、草稿或凭据。日报位于 `digests/<issue>-r<revision>.json`，存在的修订不允许覆盖。

正常运行根据前一期截止时间确定窗口，最长回看 48 小时，首次回看 24 小时。重建历史期号使用它之前的日报窗口，不使用后来覆盖时间。重新生成及回填不复用条件请求，防止 304 导致空白修订。采集到截止之后的条目时清除对应条件缓存，避免下一期漏掉这些条目。

同一事件 48 小时内不重复。显式不同版本且实体和事件类型相同可关联此前报道。没有可靠实体/版本时宁可保持分开，避免把同一机构的不同消息强行合并。跨语言无版本事件的语义归并属于 v1 的已知保守边界；AI duplicate 建议不能自动删除缺乏规则支持的事件。

规则可信门槛与评分独立：官方/直接研究来源可支持归因声明；否则需要至少两个独立媒体来源。社区只作为线索。分数为来源 30、影响 30、独立印证 15、时效 15、技术/关注 10；正常 AI 模式最终为 70% 规则分 + 30% AI 价值分。

## 不变量与失败处理

- 请求计数成功保存并在云端推送后才能调用模型。SDK 自带重试关闭；只有明确有限的服务端瞬时错误重试和一次格式修复。
- 正常最多 30 个候选单批处理，争取每期 1–3 次；主备模型切换和所有重试共享每期 5 次、滚动 24 小时 10 次硬上限。保守汇总两模型配额，不把换模型当作清零计数。
- 每期请求计数跨重新运行、诊断和修订持久化。升级旧账本时将尚未归属的旧请求保守计入首个核验期号，不清空免费额度历史。新增账本字段回滚时需使用支持该字段的版本或迁移，未知字段仍停止处理。
- 早晚时间由配置决定，默认北京时间 08:00/20:00；时间配置页将应用截止时间和云端 cron 原子更新。已冻结期号保留原截止时间，不因改时间重复推送。
- 降级不编造翻译或影响。原文摘要可公开作为简短来源信息，原始正文不归档。
- 全部来源失败不写新日报、不推进覆盖；已有同一期默认复用，显式再生成才创建新修订。
- 网站和邮件是独立副作用，网站失败不会丢掉冻结日报。邮件必须注明网站部署未确认。
- 邮件发送前先推送 sending；只有 SMTP DATA 明确接受才尝试记录 sent。任何未知状态都需要显式重发。
- Preview 不实例化 Store、不触发 AI/SMTP，不通过 Artifact 输出草稿。
- 正式 workflow 全局串行且不取消正在执行任务；仍需避免在工作流之外同时手工写同一远程数据分支。

## 许可证和外部依赖

实现代码独立编写，使用 MIT。参考 TrendRadar / Hot News Radar 的功能组织，不直接复制 GPL 代码；参考 AI News Brief 的来源覆盖方向，当前来源列表独立维护。AI Digest 未确认明确许可，不复制代码。Python/npm 依赖保留各自许可证，`twitter-text` 为 Apache-2.0。

官方接口参考：Gemini Developer API `generate_content` + `response_schema`、RSS/Atom、GitHub Releases REST、SMTP、GitHub Pages 部署。没有 OpenAI API、X API 或私人账号浏览器自动化依赖。
