## 尚需真实配置完成的验收

- Gemini 专用项目未关联付费账单：需要账号本人确认，API Key 本身无法证明。
- 模型真实返回合格中文、引用和摘要：配置后检查实际日报 `mode=ai`；规则降级不算 AI 通过。
- 生产邮箱 SMTP 接受与实际收件箱到达：分别确认正文、中文编码、两版文案和附件。
- GitHub Pages：实际页面包含当前修订标记，不能只检查 HTTP 200。
- 连续 7 天 14 个早晚时段观察，以及至少 50 条新闻的人工内容核验。

这些项目需要真实账号配置和时间观察，本地测试不能代替。系统不自动执行 X 发帖。
